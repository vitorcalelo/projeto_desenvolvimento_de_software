# Análise de Dados de Veículos US

Este é um aplicativo web interativo desenvolvido em Python utilizando Streamlit, Pandas e Plotly.

## Funcionalidades
- Histograma: Exibe a distribuição de quilometragem dos veículos (`odometer`).
- Gráfico de Dispersão: Exibe a relação entre o preço (`price`) e a quilometragem (`odometer`).
- Interatividade: O usuário pode alternar a exibição dos gráficos utilizando caixas de seleção (*checkboxes*).

## Como executar o projeto localmente
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o aplicativo: `streamlit run app.py`
